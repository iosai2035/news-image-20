A newspaper front page of Friday 20 November 2026 in one 1024×1024 image: the global AI sell-off after Anthropic's record $81.3bn IPO (Nikkei −4.7%, Kospi −5.2%, Taiex −6.2%), Cyclone Akvan's landfall near Gopalpur, COP31's draft with every mention of fossil fuels removed, Europe's Berlin talks followed hours later by Russia's overnight missile barrage on Ukraine, GTA VI's estimated $2.36bn launch day, the ICJ's genocide ruling against Myanmar, the PIF Tower hit in Riyadh, the Senate's 51–48 Iran war-powers vote, and Trump's noon press conference on Shenzhen. The page is drawn as HTML/CSS with inline SVG art and rendered once to entry.png; main.ts copies it byte-for-byte to the grader's output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
